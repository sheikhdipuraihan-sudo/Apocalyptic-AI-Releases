# Security Policy

Please do not report suspected vulnerabilities, signing-key issues, private-data exposure, or exploitable release problems in a public issue.

Use GitHub's **Report a vulnerability** flow for this repository when it is available. If that private reporting feature is unavailable, open a minimal public issue containing only the words "private security contact requested" and no exploit details, credentials, personal data, or proof-of-concept payload. The maintainer will respond with a private route when possible.

Supported security scope includes the release files and distribution configuration in this repository. Do not test against other people's devices, accounts, services, or third-party model hosts.

Users should install releases only from the official [Releases page](https://github.com/sheikhdipuraihan-sudo/Apocalyptic-AI-Releases/releases) and verify expected version information before installation.
